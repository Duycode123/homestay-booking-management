# Room image assets

Store each room's four static 4:3 images in its own kebab-case directory:

```text
standard-garden-101/
  main.jpg
  detail-1.jpg
  detail-2.jpg
  detail-3.jpg
```

Recommended source size: 1600x1200px. Reference these files from room data with
paths such as `/images/rooms/standard-garden-101/main.jpg`.
